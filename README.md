# Support Operations Analytics

Учебный pet-проект по анализу эффективности службы поддержки на Python.

## Цель проекта

Проанализировать обращения пользователей в службу поддержки и ответить на вопросы:

- Сколько времени проходит до первого ответа?
- Сколько времени занимает решение обращения?
- Какая доля обращений укладывается в SLA?
- Какие категории создают наибольшую нагрузку?
- Как различаются показатели по приоритетам и каналам?
- Как связана скорость решения с оценкой пользователя (CSAT)?

## Данные

В `data/support_tickets.csv` находится **синтетический датасет** с учебными обращениями. Это не реальные пользовательские данные.

Поля:

| Поле | Описание |
|---|---|
| ticket_id | Уникальный идентификатор обращения |
| user_id | Идентификатор пользователя |
| created_at | Время создания обращения |
| first_response_at | Время первого ответа |
| resolved_at | Время решения |
| category | Категория обращения |
| priority | Приоритет |
| channel | Канал обращения |
| agent_id | Идентификатор сотрудника поддержки |
| csat_score | Оценка пользователя от 1 до 5 |

## Метрики и допущения

В первой версии проекта используем учебные SLA:

- **Первый ответ:** до 60 минут для Critical, до 120 минут для High, до 240 минут для Medium и до 480 минут для Low.
- **Решение:** до 4 часов для Critical, до 12 часов для High, до 24 часов для Medium и до 48 часов для Low.
- **CSAT:** средняя оценка по обращениям, где пользователь оставил оценку.

Это условные правила для учебного кейса, а не отраслевые нормативы.

## Запуск

1. Создать виртуальное окружение.
2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Запустить анализ из корневой папки проекта:

```bash
python src/analysis.py
```

Результаты будут сохраняться в папку `reports/`.
